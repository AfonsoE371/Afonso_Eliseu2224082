# Descrição:

O YGOShop é uma loja online em c# que permite os utilizadores vender e comprar cartas de yugioh de outros utilizadores presentes na plataforma similarmente a sites como o cardmarket.

O projeto tem como objetivo ajudar jogadores de yugioh a obterem cartas que necessitem para melhorar os seus baralhos ou a colecionadores obterem cartas para as suas coleções.

# Requisitos de Execução
  1. Linguagem de Programação: C# (.NET Framework 4.8)
  2. Interface: Windows Forms
  3. Base de Dados: SQL Server
